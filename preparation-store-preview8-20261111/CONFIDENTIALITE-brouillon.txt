TEXTE PROPOSÉ

Haloryva Studio est une application de bureau développée par Julien Lecomte.
Elle met en valeur le curseur et permet de dessiner des annotations à l'écran.

Fonctionnement sur votre appareil
Haloryva traite les événements de souris et de clavier pour ses effets, raccourcis
et actions de boutons, y compris lorsqu'une autre fenêtre est active. L'affichage
des touches présente certaines combinaisons avec Ctrl, Alt ou Windows ; il ne
constitue pas un historique des textes saisis.
La loupe utilise temporairement les pixels autour du curseur pour les agrandir.
Les annotations, y compris le texte que vous choisissez de saisir, restent dans
la session de dessin. L'export PNG enregistre les annotations sur fond transparent
dans le fichier choisi ; ce n'est pas une capture complète du bureau.

Réglages et fichiers
Un profil JSON local conserve les préférences, dont la langue, les outils choisis
et les actions des boutons. Il peut contenir les chemins de votre logo ou son.
La version MSIX conserve ses réglages dans ses données locales d'application.
Des sauvegardes et profils invalides peuvent être conservés pour la récupération.
Les exports de profils et d'annotations sont écrits à l'endroit choisi.

Lorsque vous acceptez la reprise des réglages de la version classique, Haloryva
en crée une copie dans ses propres données. Les PNG/WAV personnalisés lisibles
peuvent être copiés avec votre consentement, dans la limite indiquée par fichier.
Une copie brute du profil source est conservée pour la récupération ; un profil
déjà présent est sauvegardé avant son remplacement accepté. Ces copies peuvent
contenir des chemins et préférences issus du profil d'origine.
Les fichiers et l'installation d'origine ne sont pas supprimés par cette opération.
Vous pouvez refuser ou annuler la proposition de reprise. Le choix de démarrage
à la connexion se règle séparément ; l'import d'un ancien profil ne vaut pas
autorisation de l'activer dans Windows.

Un journal technique local peut être créé en cas d'erreur. Le code de journalisation
conserve notamment date, catégorie, type d'erreur et pile technique, avec rotation ;
il exclut le message et les données de l'exception. Les modes de diagnostic
supplémentaires sont lancés explicitement. Aucun envoi automatique au support
n'est prévu pour ces journaux.

Réseau et partage
Les revues de sources documentées n'ont pas identifié de télémétrie applicative,
publicité ou mécanisme d'envoi vers un serveur de l'éditeur.
Les fonctions courantes ne demandent pas de compte Haloryva.
Si un export ou fichier personnalisé se trouve dans un dossier synchronisé
ou réseau, le service choisi peut le traiter selon ses propres règles.
Windows et le Microsoft Store relèvent de leurs propres services.

Vos choix et conservation
Vous pouvez modifier les préférences, désactiver les effets, régler le démarrage
dans les options prévues et dans Windows, ou quitter depuis l'icône près de l'horloge.
Les préférences permettent d'ouvrir le dossier des réglages.
Les fichiers locaux restent jusqu'à remplacement, rotation ou suppression ;
les exports et anciennes sources copiées ne sont pas supprimés par cette politique.
La reprise peut créer plusieurs copies de récupération : elles doivent être prises
en compte si vous choisissez ensuite d'effacer vos fichiers.
Haloryva ne promet pas de chiffrement propre à ces fichiers, ni de suppression
complète de toutes leurs copies à la désinstallation.
Vérifiez un profil, une annotation ou un diagnostic avant de le partager.
Un envoi volontaire au support nécessite votre action.

Actualisation : comportement MSIX de PackageContext.cs, ProfileMigration.cs et
StartupSettings.cs ; preuves import et désactivation Windows existantes.
Pas de nouvel audit exhaustif réseau, de capture réseau ou de test dans cette tâche.
Une application full trust n'est pas rendue hors réseau par l'absence d'internetClient.

Chemins techniques :
- Ancienne version classique : dossier Haloryva dans le LocalAppData réel.
- Ancien paquet de même famille : LocalCache ; migration vers LocalState/Haloryva.
- PNG/WAV copiés : ImportedAssets ; limite de code 10 Mio par fichier.
- Copie brute : migration-source-<SHA256>.json dans la destination.
- Profil remplacé : settings.before-import-<identifiant>.json dans la destination.
- Journal : Logs/errors.log avec rotation .1/.2, limites documentées antérieurement.
- Les copies conservent les informations du profil : pas de promesse d'anonymisation.
- En MSIX, StartupTask remplace l'écriture Run pour cette option. Le mode classique
  conserve son mécanisme distinct. Ne pas prétendre que la version classique a été testée ici.
