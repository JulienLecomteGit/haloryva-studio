DRAFT REVIEWER NOTES — ADAPT TO FINAL PACKAGE BEFORE SUBMISSION
Haloryva Studio is a desktop presentation and annotation utility. It runs without
a Haloryva account and uses a notification-area icon. Closing the Studio window
can leave the effects engine running; use the tray Quit command to exit normally.
The runFullTrust capability supports global input shortcuts and mouse-button actions,
transparent drawing overlays, local preferences and user-selected file exports.
No administrative elevation, driver or background service is intended.

Suggested review flow:
- Launch the app normally and open the Studio.
- Select two drawing tools, use the configured button actions, draw and undo/redo.
- Export the annotations as a transparent PNG to a user-chosen location.
- Select French, English or Spanish; restart the app to apply the saved language.
- The startup option is opt-in. Windows controls the effective permission; the app
  must respect a user-disabled task rather than re-enable it from an imported profile.
- For legacy settings, the explicit copy action offers consent; accepted supported
  PNG/WAV files are copied to package data while original files remain unchanged.
  This does not uninstall the legacy application or transfer its startup registration.
- Quit normally from the notification-area menu.
