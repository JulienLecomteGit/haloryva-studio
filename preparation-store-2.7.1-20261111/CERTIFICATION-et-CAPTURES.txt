NOTES POUR LE CERTIFICATEUR — BROUILLON, NON SOUMIS
Haloryva Studio is a desktop presentation and annotation utility. It does not require
a Haloryva account. Closing the Studio window can leave the application running;
use the notification-area Quit command to exit normally.
The runFullTrust capability supports global input shortcuts and mouse-button actions,
transparent annotation overlays, local preferences and user-selected exports.
No administrative elevation, driver or background service is intended.
Select two drawing tools, cycle through them using the configured mouse actions,
draw and undo/redo, and export annotations as a transparent PNG.
Choose French, English or Spanish in Preferences, then restart the application
to apply the saved language.
Startup is opt-in and follows the effective Windows permission. Importing settings
must not enable a user-disabled startup task.
The legacy-settings copy is consent-based. Supported PNG/WAV resources are copied
independently; originals are preserved. This does not uninstall the classic application
or transfer its startup registration.
Use a non-personal profile for review. Final package-specific instructions and
the results of actual Windows-logon qualification must be added before submission.
