// Pas de référence WinRT dans les classes de hooks ou le moteur de dessin.
internal enum StartupAvailability
{
    Disabled, Enabled, DisabledByUser, DisabledByPolicy,
    EnabledByPolicy, Unknown
}
internal sealed class StartupSnapshot
{
    internal StartupAvailability Availability;
    internal bool? EffectiveEnabled; // null lorsque la lecture est impossible
    internal bool CanChange;
    internal string MessageKey;      // clé traduite ; pas de texte technique brut
}
internal interface IStartupSettings
{
    System.Threading.Tasks.Task<StartupSnapshot> ReadAsync();
    System.Threading.Tasks.Task<StartupSnapshot> ChangeFromUserAsync(bool desired);
}

Points obligatoires de l'adaptateur empaqueté :
- vérifier PackageContext.Packaged ; aucune utilisation en session d'essai ;
- sérialiser les demandes à l'aide d'un verrou asynchrone ;
- appeler GetAsync avec le TaskId constant ;
- traiter les cinq valeurs de StartupTaskState sans convertir toute valeur
  inconnue en Disabled ;
- conserver les états de refus ; journal technique via ErrorReporting ;
- après modification, relire State et renvoyer le résultat obtenu.

Noyau logique à intégrer dans cet adaptateur :
var task = await Windows.ApplicationModel.StartupTask.GetAsync(
    "HaloryvaStudioStartup");
var state = task.State;
if (state == Windows.ApplicationModel.StartupTaskState.Disabled && desired)
{
    await task.RequestEnableAsync();
}
else if (state == Windows.ApplicationModel.StartupTaskState.Enabled && !desired)
{
    task.Disable();
}
// Les autres états ne sont pas forcés. Relire et traduire task.State.
// Une exception donne Unknown, jamais un repli dans HKCU Run.

L'enrobage ci-dessus (verrou, mapping, exceptions, durée de vie) est requis
avant emploi ; le fragment seul n'est pas le service final.

5. COPIE DE PROFIL — CONTRAT
ReadCandidate(path) : lecture bornée et validation en mémoire ; aucun Move,
Delete, Save, ApplyAutoStart ou Repair sur le chemin source.
PrepareMigration(candidate, target, consent) : plan sans écriture ; profil
normalisé, copies PNG/WAV éventuelles, différences attendues.

unique puis File.Move sans écrasement pour premier profil ; File.Replace avec
sauvegarde pour un remplacement expressément confirmé.

au moment du commit. En cas de concurrence, abandonner au lieu d'écraser.

connues ; aucun contenu de profil personnel ni chemin utilisateur dans les
journaux publics GitHub.
