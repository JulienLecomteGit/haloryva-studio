# Diffusion et transparence — Haloryva Studio 2.7.1

## Canal retenu

Microsoft Store est le téléchargement principal. La 2.7.1 est certifiée et sa publication a été autorisée uniquement pour le groupe privé. Aucun passage automatique au public n’est configuré. Ce document ne vaut pas autorisation de changer l’audience.

[Fiche Store](https://apps.microsoft.com/detail/9NJ14SZJP55B) · [Installation](INSTALLATION.md) · [Confidentialité](confidentialite/README.md)

L’EXE autonome 2.7.1 reste conservé hors de cette intégration et n’est pas proposé au téléchargement. La certification Store ne signe pas cet EXE. Les anciens fichiers de releases restent historiques.

## Preuves acquises et limites

- Certification Microsoft acquise pour le MSIX 2.7.1.0 x64.
- Signature Store et état OK lus pour le paquet installé ; binaire installé 2.7.1.11 comparé à l’empreinte du binaire validé, identique.
- Installation, langues, reprise d’anciens réglages, redémarrage automatique et reconnexion avec conservation des préférences réussis selon les essais utilisateur.
- Installation sur un autre PC avec protection intelligente activée, boutons et traînée fonctionnels selon l’utilisateur.
- Les tests automatisés antérieurs et les essais utilisateurs sont des preuves distinctes. Aucun nouveau test produit n’a été lancé pour cette préparation documentaire.

Ces éléments ne qualifient pas toutes les versions Windows, tous les matériels, profils ou fichiers PNG/WAV. WACK local n’a pas été exécuté ; la certification Microsoft a été acquise par la soumission Store. La cible 25H2/26H2 Intel/AMD ne constitue pas une garantie universelle. Aucun support Windows 10 ou ARM64 natif n’est annoncé.

Les sources actuellement présentes dans ce dépôt restent la base historique 2.7.0. Cette branche documentaire ne les remplace pas par les sources estampillées du binaire 2.7.1.11.
