# Haloryva Studio 2.7.1 — Microsoft Store

[Français](../fr/README.md) · [Home](../../README.md) · [Español](../es/README.md)

Install from the public Microsoft Store listing. Availability depends on country and device.

Installation
Official listing: https://apps.microsoft.com/detail/9NJ14SZJP55B
Check Haloryva Studio and publisher Julien Lecomte. Choose Get or Install, then Open. This channel does not require a separate EXE installer or certificate.
The x64 package targets Intel/AMD PCs and declares Windows 10.0.26200.0 as its minimum. Windows 11 25H2/26H2 are the selected targets; available trials do not qualify every Windows version and hardware combination. The Store checks declared requirements for your device. Keyboard and mouse required.

Moving from an older version
Export your profile and separately save custom PNG/WAV assets and drawings. Fully exit the old app from its notification-area icon before opening the Store version.
The Store version has separate settings. If import is offered, read the summary and accept, decline or cancel. Copying does not remove the old installation or its data. Do not assume that EXE and Store settings synchronize. Import from an earlier installation succeeded in a user trial; this does not guarantee every profile or asset.
If you keep the old version, disable its automatic startup and keep startup enabled only for the version you use. Do not run both versions together. Store startup is optional and requires a deliberate choice; Windows startup controls take priority.

Use and updates
Choose French, English or Spanish in preferences, then fully quit and restart the app to apply the language. Closing only the Studio window can leave the engine running near the clock.
Use Microsoft Store updates for this channel. The EXE setup does not update the Store installation. Keep a backup of important settings.

Uninstallation
Export the profile and save PNG/WAV assets and drawings outside app data. Quit Haloryva from its notification-area icon, then use Windows Settings > Apps > Installed apps > Haloryva Studio > Uninstall.
Windows may remove Store app data, including imported assets. Do not rely on reinstalling to recover them. Exports and copies stored elsewhere must be managed separately. The EXE uninstaller’s retention option does not apply to the Store.
