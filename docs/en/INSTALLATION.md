# Haloryva Studio — 2.7.2 update via Microsoft Store

[Français](../fr/README.md) · [Home](../../README.md) · [Español](../es/README.md)

**2.7.2 has passed Microsoft Store certification.** The Store update from 2.7.1 has been verified on the tested PC. The latest Partner Center capture still showed publication in progress; its final status and availability on other devices have not been verified. Check the [distribution status](../DIFFUSION.md) and the version offered by Microsoft Store.

## Installing from Microsoft Store

Official listing: https://apps.microsoft.com/detail/9NJ14SZJP55B
Check Haloryva Studio and publisher Julien Lecomte. Choose Get or Install, then Open. This channel does not require a separate EXE installer or certificate.
The certified 2.7.2.0 package targets Intel/AMD x64 PCs and retains Windows 10.0.26200.0 as its declared minimum. Windows 11 25H2/26H2 are the selected targets; available trials do not qualify every Windows version and hardware combination. The Store checks declared requirements for your device. Keyboard and mouse required.

## Updating an existing Store installation

Once version 2.7.2 is actually offered:

1. In Haloryva, export a copy of important settings and separately keep your PNG/WAV assets.
2. Fully quit Haloryva from its icon near the clock.
3. Open Microsoft Store and check for app updates. Apply the Haloryva Studio update if it is offered.
4. Open Haloryva, then About: check that the displayed version is **2.7.2**. Check your settings and automatic-startup status.

Updating the same Store package keeps the existing channel; this operation does not require uninstalling or importing an EXE profile. Check your settings and startup on your own device after updating. If the Store still offers 2.7.1, the presence of 2.7.2 source code on GitHub cannot force its availability.

The 18 November 2026 update from 2.7.1 to 2.7.2 preserved the existing settings on the tested PC; the profile file was unchanged byte for byte. Relaunch, visual effects and startup after signing in still await confirmation for this release. [Evidence and limits](../VALIDATION-2.7.2.md).

## Moving from an older EXE installation to the Store

Export your profile and separately save custom PNG/WAV assets and drawings. Fully exit the old app from its notification-area icon before opening the Store version.
The Store version has separate settings. If import is offered, read the summary and accept, decline or cancel. Copying does not remove the old installation or its data. Do not assume that EXE and Store settings synchronize. Import from an earlier installation succeeded in a user trial; this does not guarantee every profile or asset.
If you keep the old version, disable its automatic startup and keep startup enabled only for the version you use. Do not run both versions together. Store startup is optional and requires a deliberate choice; Windows startup controls take priority.

## Use and updates

Choose French, English or Spanish in preferences, then fully quit and restart the app to apply the language. Closing only the Studio window can leave the engine running near the clock.
Use Microsoft Store updates for this channel. The EXE setup does not update the Store installation. Keep a backup of important settings.

## Uninstallation

Export the profile and save PNG/WAV assets and drawings outside app data. Quit Haloryva from its notification-area icon, then use Windows Settings > Apps > Installed apps > Haloryva Studio > Uninstall.
Windows may remove Store app data, including imported assets. Do not rely on reinstalling to recover them. Exports and copies stored elsewhere must be managed separately. The EXE uninstaller’s retention option does not apply to the Store.
