# Haloryva Studio — Support

[Français](../fr/README.md) · [Home](../../README.md) · [Español](../es/README.md)

Public support: https://github.com/JulienLecomteGit/haloryva-studio/issues
Check existing issues before opening one. GitHub may require an account to post; normal app functions do not require a Haloryva account.
Issues and attachments are public. No private channel is currently offered: do not post confidential data, personal documents or sensitive security details in a public issue.
Include the Haloryva version, Store or EXE channel, Windows version, reproduction steps and actual result. For display problems, include resolution and scaling. Review Copy version information before sharing; a complete profile or log is not requested by default.
To exit fully, use Quit Haloryva near the clock. A changed language applies on the next full launch. Back up settings before any reset. If Windows blocks a file, leave protections enabled and note the exact message.
No response time is guaranteed. The three-month rule planned for possible future private support does not apply to public issues. See [Privacy](../confidentialite/en.md) in this folder.
