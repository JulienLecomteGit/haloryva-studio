# Release notes — Haloryva Studio 2.7.2

[Français](../fr/README.md) · [Home](../../README.md) · [Español](../es/README.md)

**2.7.2 is being prepared:** the code is based on the validated exp4 build, but the final release build, its native tests and Store certification for 2.7.2 still need confirmation. The last documented public release is 2.7.1. [Validation status](../VALIDATION-2.7.2.md).

- Continuous Line / Light trails, adaptive curves and progressive fading.
- Explained trail settings and a preview shared with the rendering engine.
- Timestamped mouse samples that preserve movement order.
- Less redundant work when compositing and copying the ribbon.
- Conditional effect-overlay recovery with a bounded local log.
- Background log writing; detailed diagnostics enabled only on request.
- Normal startup and version history prepared for the final release.

Prepared identities: displayed version 2.7.2; file 2.7.2.6; assembly 2.7.2.0; target Store package 2.7.2.0 x64.

## Features retained from 2.7.1

- French, English and Spanish interface with a saved language preference.
- Saved selection of drawing tools cycled by mouse buttons.
- Improvements to short clicks, input handling and initial Studio placement.
- Tool, color and thickness remain fixed throughout each stroke.
- Refined text, indicators and version history.
- Consented import of older settings and compatible assets into the Store version.
- Store startup management and refreshed status when returning to the Studio.
