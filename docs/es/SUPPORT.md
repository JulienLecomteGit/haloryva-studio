# Haloryva Studio — Support

[Français](../fr/README.md) · [English](../en/README.md) · [Inicio](../../README.md)

Soporte público: https://github.com/JulienLecomteGit/haloryva-studio/issues
Consulta las incidencias existentes antes de crear una. GitHub puede exigir una cuenta para publicar; las funciones habituales no requieren una cuenta Haloryva.
Las incidencias y sus archivos adjuntos son públicos. Actualmente no se ofrece un canal privado: no publiques datos confidenciales, documentos personales ni detalles sensibles de seguridad.
Indica la versión Haloryva, canal Store o EXE, versión Windows, pasos para reproducir y resultado obtenido. Para problemas visuales, añade resolución y escala. Revisa Copiar información de versión antes de compartir; no se solicita por defecto un perfil o registro completo.
Para salir completamente, utiliza Salir de Haloryva junto al reloj. Un cambio de idioma se aplica en el siguiente inicio completo. Guarda una copia de los ajustes antes de restablecerlos. Si Windows bloquea un archivo, conserva las protecciones y anota el mensaje exacto.
No se garantiza un plazo de respuesta. La regla prevista de tres meses para un posible soporte privado futuro no se aplica a las incidencias públicas. Consulta [Privacidad](../confidentialite/es.md) en esta carpeta.
