# Haloryva Studio 2.7.1 — Microsoft Store

[Accueil](../../README.md) · [English](../en/README.md) · [Español](../es/README.md)

Installation depuis la fiche publique Microsoft Store. La disponibilité dépend du pays et de l’appareil.

Installation
Fiche officielle : https://apps.microsoft.com/detail/9NJ14SZJP55B
Vérifiez le nom Haloryva Studio et l’éditeur Julien Lecomte. Choisissez Obtenir ou Installer, puis Ouvrir. Aucun installateur EXE ni certificat à installer séparément n’est nécessaire pour ce canal.
Paquet x64 destiné aux PC Intel/AMD, minimum déclaré Windows 10.0.26200.0. La cible retenue est Windows 11 25H2/26H2 ; les essais disponibles ne constituent pas une qualification exhaustive de ces versions et de tous les matériels. Le Store vérifie les exigences déclarées pour votre appareil. Clavier et souris requis.

Passage depuis une ancienne version
Exportez votre profil et gardez séparément les PNG/WAV personnels et les dessins utiles. Quittez complètement l’ancienne application depuis son icône près de l’horloge avant d’ouvrir le Store.
La version Store utilise ses propres réglages. Si une reprise est proposée, lisez le résumé et acceptez, refusez ou annulez. La copie ne supprime ni l’ancienne installation ni ses données. Ne supposez pas une synchronisation entre EXE et Store. La reprise depuis une ancienne installation a réussi lors d’un essai utilisateur ; cela ne garantit pas chaque profil ou ressource.
Si vous conservez l’ancienne version, désactivez son démarrage automatique et gardez seulement celui de la version que vous utilisez. Ne lancez pas les deux versions simultanément. Le démarrage Store est facultatif et doit être autorisé volontairement ; le choix effectué dans Windows reste prioritaire.

Utilisation et mise à jour
Choisissez français, anglais ou espagnol dans les préférences, puis quittez complètement l’application et relancez-la pour appliquer la langue. Fermer uniquement le Studio peut laisser le moteur actif près de l’horloge.
Utilisez les mises à jour Microsoft Store pour ce canal. Le setup EXE ne met pas à jour l’installation Store. Conservez une copie des réglages importants.

Désinstallation
Exportez le profil et sauvegardez les PNG/WAV et dessins hors des données de l’application. Quittez Haloryva depuis son icône près de l’horloge, puis utilisez Paramètres Windows > Applications > Applications installées > Haloryva Studio > Désinstaller.
Windows peut supprimer les données Store, y compris les ressources importées. Ne comptez pas sur une réinstallation pour les récupérer. Les exports et copies stockés ailleurs restent à gérer séparément. L’option de conservation du désinstalleur EXE ne s’applique pas au Store.
