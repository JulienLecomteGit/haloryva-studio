# Haloryva Studio — Support

[Accueil](../../README.md) · [English](../en/README.md) · [Español](../es/README.md)

Assistance publique : https://github.com/JulienLecomteGit/haloryva-studio/issues
Consultez les signalements existants avant d’en créer un. GitHub peut demander un compte pour publier ; aucun compte Haloryva n’est requis pour les fonctions courantes de l’application.
Les tickets et pièces jointes sont publics. Aucun canal privé n’est actuellement proposé : n’envoyez aucune donnée confidentielle, document personnel ou détail sensible de sécurité dans un ticket public.
Indiquez la version Haloryva, le canal Store ou EXE, la version Windows, les étapes de reproduction et le résultat obtenu. Pour un défaut visuel, ajoutez la résolution et la mise à l’échelle. Relisez « Copier les informations de version » avant partage ; un profil ou journal complet n’est pas demandé par défaut.
Pour quitter complètement, utilisez Quitter Haloryva près de l’horloge. Une langue modifiée s’applique au prochain lancement complet. Sauvegardez les réglages avant toute réinitialisation. Si Windows bloque un fichier, gardez les protections actives et relevez le message exact.
Aucun délai garanti de réponse. La règle prévue de trois mois pour un éventuel futur support privé ne s’applique pas aux tickets publics. Voir [Confidentialité](../confidentialite/fr.md) dans ce dossier.
