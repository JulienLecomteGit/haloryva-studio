NOTES POUR L'ÉVALUATEUR MICROSOFT — BROUILLON EN ANGLAIS
To be finalized with the production package identity and actual support URLs.

Haloryva Studio is a Windows desktop app for pointer effects and screen
annotations. No Haloryva account or login credentials are required.
The interface supports French, English and Spanish. The selected language is
saved and applied the next time the application starts. Closing only the
Studio window can leave the application running in the notification area.

The runFullTrust capability is needed for this Win32 Windows Forms app:
desktop overlays, global mouse/keyboard hooks for user-selected shortcuts and
button actions, a notification-area icon, local settings and user-selected
file exports. The app runs in the interactive user's desktop session.
It is not designed to require elevation or install a driver or service.
The package does not request allowElevation.

Suggested review route for the final package:
1. Start Haloryva from the Start menu and open its Studio.
2. In drawing settings, select Pen and Rectangle for tool cycling.
   At least one drawing tool must remain selected.
3. Assign a middle/side mouse button to the next-tool action; short and long
   presses have separate assignments. Use an appropriate physical mouse.
4. Draw annotations, undo/redo, and export them as a transparent PNG.
5. Choose a language in preferences. Quit the application completely through
   its notification-area menu, then relaunch. Inspect the language and tools.
6. Close the Studio window to check notification-area access. Use Quit to exit.
The magnifier is separate from annotation export. Annotation PNG exports are
not full screenshots of the desktop.
No diagnostic command line or unsigned-installation procedure is part of a
normal Store installation.

Do not submit these notes until automatic startup and the migration/update
policy have been resolved for the final package. Add the chosen behavior here.
Do not claim that Microsoft's reviewers have already performed this route.
The existing MSIX evidence covers launch/normal shutdown and profile
persistence on a temporary test identity; it is not a certification report.
