NOTES POUR L'ÉVALUATEUR MICROSOFT — BROUILLON EN ANGLAIS
Update these notes to match the final package and language before submission.

Haloryva Studio is a Windows desktop application for pointer effects and screen
annotations. It requires no Haloryva account or login credentials.

The runFullTrust capability is required because the package contains a Win32
Windows Forms application. It uses desktop overlays, global mouse/keyboard
hooks for user-configured shortcuts and mouse actions, a notification-area
icon, and local settings and user-selected file exports. These functions run
in the interactive user's desktop session. The application is not designed
to require elevation or install a service or driver. It does not request the
allowElevation capability.

To inspect the current French interface:
1. Start Haloryva from the Start menu. The Studio opens on the current display.
2. Open Dessin > Défilement. Select Stylo and Rectangle; keep at least one tool.
3. In Boutons souris, assign a supported button to Outil de dessin suivant.
   A long-press action can be assigned separately. Use a middle or side button
   available on the test mouse; avoid replacing a primary click unnecessarily.
4. Use Dessiner to annotate; verify the chosen tools cycle as configured.
5. Return to the Studio and use Annuler/Rétablir and Exporter PNG.
6. Close the Studio. Haloryva remains accessible from its notification-area
   icon; Quitter Haloryva exits the application completely.
7. Relaunch it and inspect the saved selection and button assignments.
The annotations are exported on a transparent background. The magnifier is
a separate optional screen effect.
No command line diagnostic mode or unsigned-installation procedure is needed
for an ordinary Store installation.

Do not claim these steps were performed by Microsoft's certification team.
The current test package is a prototype identity, not the submission package.
