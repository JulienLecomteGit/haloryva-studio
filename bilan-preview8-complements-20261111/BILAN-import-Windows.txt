2. DÉSACTIVATION PAR WINDOWS : 5 ASSERTIONS RÉUSSIES
https://github.com/JulienLecomteGit/haloryva-studio/actions/runs/43021089861

Une activation unique depuis le Studio sert de préparation nécessaire. L’ancienne suite d’activation/désactivation n’est pas répétée.
Le pilote ouvre la vraie page Windows « Applications > Démarrage » (ms-settings:startupapps), trouve l’unique interrupteur « Haloryva Studio Lifecycle Test », puis le passe de On à Off via l’accessibilité de cette interface.
Windows enregistre réellement State=1 (désactivé par l’utilisateur), et non un état de service fictif. Le pilote ne modifie aucune valeur du Registre : il le consulte uniquement pour vérifier le résultat.
Après arrêt et relancement normaux de Haloryva, le contrôle de démarrage est désactivé dans le Studio. Le profil contient toujours LaunchAtLogin=true, mais cette valeur ne réactive pas Windows.
Le paquet de test est retiré à la fin.

LIMITE PRÉCISE SUR LA FENÊTRE DÉJÀ OUVERTE
Le retour du focus vers le Studio n’a pas été confirmé par l’environnement GitHub (LiveFocusConfirmed=false). Avant relancement, son interrupteur est resté utilisable, alors que Windows était déjà à State=1.
Le rafraîchissement immédiat au retour réel du focus n’est donc PAS validé. Ce constat ne prouve pas le comportement après un véritable retour utilisateur au premier plan. Le respect du choix Windows après relancement est, lui, réellement validé.
Le pilote n’a ni forcé un événement Activated fictif ni contourné les protections Windows pour présenter cette partie comme réussie.

CE QUI RESTE NON EXÉCUTÉ
- Rafraîchissement immédiat après un retour réel du focus au Studio.
- Ouverture de session Windows réelle et lancement automatique à cette occasion.
- Migration/coexistence avec une installation réelle stable 2.7.0.
- Dialogues d’avertissement pour fichiers personnalisés inaccessibles ou trop volumineux ; seuls les fichiers PNG/WAV valides et les refus de consentement décrits ci-dessus sont couverts.
- Parcours générique du sélecteur de fichier JSON.
- Validation native Windows 11 x64 et certification Microsoft Store.
Ces points ne sont pas transformés en résultats positifs par les deux jobs verts.
