Informations utiles
- Version affichée dans À propos ; installation EXE ou Microsoft Store.
- Version de Windows, langue de l’interface, résolution et mise à l’échelle si l’affichage est concerné.
- Quelques étapes pour reproduire, résultat attendu, résultat obtenu et message exact après retrait des données privées.
- Un exemple non personnel ; une capture recadrée sur le problème uniquement si nécessaire.
Le bouton « Copier les informations de version » peut aider : relisez le texte
avant de le partager. Un profil ou journal complet n’est pas demandé par défaut.

Conseils
Fermer le Studio peut laisser Haloryva actif. Utilisez « Quitter Haloryva » dans
son icône près de l’horloge pour le fermer complètement.
Une nouvelle langue s’applique au prochain lancement complet.
Si Windows bloque un fichier, conservez ses protections, relevez le message et
contactez le support. Ne remplacez pas l’installateur par un fichier non officiel.
Ne supprimez pas vos réglages pour résoudre un problème sans les avoir sauvegardés.
